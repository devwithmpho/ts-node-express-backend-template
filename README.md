# TS Node Express Backend Template

A simple backend template using TypeScript, Node.js, and Express.

## Features

-   TypeScript with strict typing
-   Express server with type support
-   Nodemon for live reloading in development
-   Build script for production
-   Environment variables via `.env`

## Getting Started

1. Clone the template:

```bash
git clone https://github.com/YOUR_USERNAME/ts-node-express-backend-template.git
cd ts-node-express-backend-template
```

2. Install dependencies

```bash
npm install
```

3. Run development server

```bash
npm run dev
```

4. Build for production

```bash
npm run build
npm run start
```
